# Web/app học tập — Hóa học 8, Ôn tập kiểm tra giữa kì II

**Ôn tập kiểm tra giữa kì II (Bài 8–11: Acid, base, oxide và muối)**
Môn Khoa học tự nhiên 8 (phân môn Hóa học) — Chương trình GDPT 2018, sách Kết nối tri thức với cuộc sống.

Giáo viên: Lê Văn Thắng — Trường TH và THCS Phước Hưng, xã Nhơn Hội, tỉnh An Giang.

## Nội dung

Web/app học tập 6 phần: Khởi động, Hệ thống kiến thức (Bài 8–11), Mô phỏng, Sơ đồ tư duy, Luyện tập (10 câu trắc nghiệm tự chấm), Vận dụng.

Mô phỏng gồm:
1. Nhận biết 3 dung dịch HCl, NaOH, NaCl bằng giấy quỳ tím và phenolphthalein.
2. Phản ứng trung hoà NaOH + HCl (Thí nghiệm 2, Bài 9) — 4 bước, 3 ống nghiệm.
3. Tính chất hoá học của muối — 4 ống nghiệm (Hình 11.1, Bài 11).

**Khóa đáp án trắc nghiệm: 1A 2C 3A 4C 5D 6A 7C 8B 9D 10B.**
(Câu 5 đã xáo vị trí phương án so với deck gốc — key gốc 1A 2C 3A 4C 5C 6A 7C 8B 9D 10B — để phân bố đáp án đều A/B/C/D.)

## Cách dùng

- Mở file `index.html` bằng trình duyệt bất kì (không cần máy chủ).
- Học sinh đăng nhập bằng Họ tên + Lớp, học 6 phần, làm 10 câu trắc nghiệm rồi nộp bài.
- Điểm tự động lưu về Google Sheets của giáo viên (qua Apps Script Web App, chạy bằng tài khoản giáo viên).

## File trong repo

- `index.html` — web/app hoàn chỉnh, tự chứa (hình ảnh nhúng base64).
- `Web_Hoc_Tap_Hoa8_OnTap_GKII.md` — bản sao toàn bộ mã nguồn kèm khóa đáp án.
- `Code.gs` — Apps Script Web App ghi điểm về tab KetQua của Sheet bài này.
- `assets-flow/` — 3 ảnh nền gốc (Gemini, 1376×768) + logo cá nhân của Thầy.
